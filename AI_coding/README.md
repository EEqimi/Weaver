# 文思工坊 Weaver

> 让每个有故事的人，都能成为真正的写作者。

## 一、项目简介

**文思工坊**（英文名：Weaver，取"织工"之意，喻指将灵感编织成故事）是一个基于大语言模型的**多智能体协作叙事生成系统**。它将文学创作这一高度复杂的创造性任务，拆解为七个可管理、可迭代的子任务，由不同的智能体节点协同完成，同时允许用户在每一个环节深度参与和修改，形成**人机协作的创作闭环**。

### 核心理念

- **流程透明化**：每个节点的结果可查看、可编辑，告别"黑箱"生成
- **步骤可控化**：用户可自动推进、手动编辑或返回重做，始终在创作主驾驶位
- **风格可调化**：支持多位作家风格的细粒度混合
- **过程可学化**：不仅产出作品，更记录完整的"创作日志"

## 二、核心工作流

系统将文学创作拆解为七个节点，形成完整的工作流：

**灵感 → 深化 → 人物 → 情节 → 生成 → 润色 → 迭代**

> 💡 用户可在任意节点介入，支持三种操作：**自动推进** / **手动编辑** / **返回重做**

|  步骤 | 节点名称      | 核心功能               | 输入       | 输出          |
| :-: | :-------- | :----------------- | :------- | :---------- |
|  1  | **灵感捕捉器** | 将零散想法扩展为多个可发展的故事方向 | 用户的一句话想法 | 3-5个具体故事方向  |
|  2  | **主题深化师** | 提炼核心命题、情感基调与关键词    | 选定的故事方向  | 主题陈述+基调+关键词 |
|  3  | **人物工坊**  | 生成主要角色的人物小传、性格与动机  | 主题与基调    | 人物设定卡片集     |
|  4  | **情节建筑师** | 基于叙事模型生成故事大纲与转折点   | 主题+人物    | 结构化的情节大纲    |
|  5  | **章节作家**  | 逐章生成完整的叙事文本        | 大纲+人物    | 故事初稿        |
|  6  | **风格调色盘** | 按指定风格（或混合风格）进行文学润色 | 初稿+风格指令  | 风格化定稿       |
|  7  | **评价迭代器** | 多维度评分并提供修改建议       | 定稿       | 评分+改进清单     |

在基础工作流之上，系统设计了三个差异化亮点模块：

### 风格混合器（Style Blender）

支持**两种及以上作家风格的混合**，实现细腻的风格控制。

- 示例："用 40% 张爱玲的细腻 + 40% 王小波的幽默 + 20% 博尔赫斯的奇幻"

### 版本对比器（Version Comparator）

同一故事可生成多个版本，用户可并排对比、择优发展：

- 悲剧版 vs 喜剧版
- 古典叙事版 vs 现代主义版
- 第一人称版 vs 第三人称版

### 创作日志（Creative Log）

自动记录用户在每一步的修改决策与AI的输出演变，生成完整的**"创作手记"**，使创作过程本身成为可回溯、可学习的对象。

│   ├── base_agent.py                # 公共基类：封装通用的调用逻辑、记忆管理和解析方法

│   ├── character_workshop.py        # 人物工坊：角色设定、性格塑造与人物关系构建
│   ├── plot_architect.py            # 情节建筑师：故事情节的结构设计与节奏把控
│   ├── chapter_writer.py            # 章节作家：根据大纲逐章生成完整的叙事文本
│   ├── style_palette.py             # 风格调色盘：按指定风格或混合风格进行文学润色
│   └── evaluation_iterator.py       # 评价迭代器：多维度评分并提供修改建议
│
├── utils/                           # 工具函数
│   ├── __init__.py                  # 空文件，标识为包
│   ├── config.py                    # API统一配置：管理密钥、模型等环境信息
│   └── adapter.py                   # 万能翻译器：把用户的"大白话"翻译成程序能听懂的结构化输入
│
├── main.py                          # 主程序入口：串联所有节点，构建创作流水线
│
└── app_streamlit.py                 # 网页界面：Streamlit前端，提供用户与智能体交互的操作台
