# 文思工坊（Weaver）

**让每个有故事的人，都能成为真正的写作者。**

## 一、项目简介

### 1.1 一句话描述

文思工坊是一个基于大语言模型的人机协作叙事生成系统，将文学创作拆解为七个可管理、可迭代的步骤，让用户在AI的陪伴下完成从灵感到成品的完整创作旅程。

### 1.2 核心理念

我们相信：**AI不应该替代写作者，而应该成为写作者的伙伴。**

文思工坊不做"一键生成小说"的黑箱工具，而是构建了一个**透明、可控、可学习**的创作流程。用户始终在驾驶位，AI是副驾驶和工具箱。

### 1.3 目标用户

- 有创作冲动但缺乏写作经验的故事爱好者
- 需要快速产出叙事内容的自媒体人、编剧、游戏策划
- 对文学创作方法论感兴趣的学习者

## 二、解决的问题

| 痛点 | 文思工坊的解法 |
|---|---|
| 灵感模糊，不知从何下手 | 灵感捕捉器将一句话扩展为多个具体方向 |
| 故事写得"散"或"浅" | 主题深化师帮用户提炼核心命题 |
| 人物扁平、脸谱化 | 人物工坊生成有欲望、有恐惧、有弧光的立体角色 |
| 情节混乱、节奏失控 | 情节建筑师提供叙事模型，组织场景级大纲 |
| 文字干瘪、没有质感 | 风格调色盘支持混合多位作家风格进行润色 |
| 写完后不知好坏 | 评价迭代器多维度评分，给出具体修改建议 |
| 只得到作品，没学到方法 | 创作日志记录全过程，成为可复用的学习档案 |

## 三、七步创作流程

文思工坊将文学创作拆解为以下七个节点，形成完整的创作闭环：

```
灵感捕捉器 → 主题深化师 → 人物工坊 → 情节建筑师 → 章节作家 → 风格调色盘 → 评价迭代器
```

### 3.1 节点一览

| 步骤 | 节点名称 | 核心功能 | 输入 | 输出 |
|---|---|---|---|---|
| 1 | 灵感捕捉器 | 将一句话想法扩展为多个具体故事方向 | 用户的灵感种子 | 3-5个结构化方向卡片 |
| 2 | 主题深化师 | 提炼核心命题、情感基调与关键词 | 选定的方向卡片 | 主题陈述 + 基调 + 关键词体系 |
| 3 | 人物工坊 | 生成有深度的人物设定 | 主题 + 方向 | 完整人物卡片 + 关系图谱 |
| 4 | 情节建筑师 | 基于叙事模型生成场景级大纲 | 主题 + 人物 | 分章情节大纲 |
| 5 | 章节作家 | 逐章生成通顺的叙事文本 | 大纲 + 人物 | 完整故事初稿 |
| 6 | 风格调色盘 | 混合文学风格进行润色 | 初稿 + 风格选择 | 风格化定稿 + 多版本 |
| 7 | 评价迭代器 | 多维度评分并提供修改建议 | 定稿 | 评分报告 + 创作日志 |

### 3.2 关键机制：用户随时介入

在每个节点，用户都可以：

| 操作 | 说明 |
|---|---|
| 多轮对话 | 用户反复打磨输出结果 |
| 确认推进 | 接受当前结果，进入下一步 |
| 手动编辑 | 直接修改当前节点的输出内容 |
| 返回重做 | 回到前一步骤调整后再来 |

这让用户始终是创作的主导者，而非被动的内容接收者。

## 四、特色功能

### 4.1 风格混合器

用户可以选择两种及以上作家的风格进行混合，实现精细的风格控制。

**示例**：「40%张爱玲的细腻 + 40%王小波的幽默 + 20%博尔赫斯的奇幻」

支持两种选择方式：
- **按作家选择**：张爱玲、王小波、博尔赫斯等
- **按标签选择**：细腻心理描写、冷峻短句、奇幻隐喻等

并提供**高级模式**，允许用户调整词汇、句式、修辞等维度的偏好。

### 4.2 版本对比器

同一故事可生成多个风格版本，用户可以：

- 在版本间并排对比
- 逐段选择"用A版的这一段 + B版的另一段"
- 保存所有历史版本，随时回溯

### 4.3 创作日志

系统自动记录用户在每一步的决策与AI的输出演变，生成一份完整的**"创作手记"**，包含：

- 创作流程图
- 各节点的关键决策记录
- 评价迭代历史
- 最终成品

使用户在写作中学习写作。

## 五、篇幅自适应

系统根据用户选择的篇幅，自动调整人物数量和情节复杂度：

| 篇幅 | 人物数量 | 建议章节数 |
|---|---|---|
| 短篇（1-5万字） | 3-5人 | 5-10章 |
| 中篇（5-30万字） | 8-15人 | 15-30章 |
| 长篇（30万字以上） | 15-30+人 | 30-60章 |

用户也可以在每个节点手动调整具体数量。

## 六、灵活的工作模式

### 6.1 标准模式：从头开始

从灵感捕捉器开始，完整走完七个步骤，获得从0到1的完整创作体验。

### 6.2 任意节点切入

用户可以从任何一个节点开始工作：

| 入口 | 适用场景 |
|---|---|
| 已有故事方向 | 直接进入主题深化师 |
| 已有人物设定 | 直接进入情节建筑师 |
| 已有完整草稿 | 直接进入风格调色盘进行润色 |
| 已有写了一半的小说 | 直接进入章节作家，上传文件续写 |

### 6.3 独立工具模式

用户可以直接上传已有文本，使用单个节点的功能：

- 上传草稿 → 风格调色盘润色
- 上传稿件 → 评价迭代器评分
- 上传未完稿 → 章节作家续写

```
│   ├── character_workshop.py        # 人物工坊：角色设定、性格塑造与人物关系构建
│   ├── plot_architect.py            # 情节建筑师：故事情节的结构设计与节奏把控
│   ├── chapter_writer.py            # 章节作家：根据大纲逐章生成完整的叙事文本
│   ├── style_palette.py             # 风格调色盘：按指定风格或混合风格进行文学润色
│   └── evaluation_iterator.py       # 评价迭代器：多维度评分并提供修改建议
│
├── utils/                           # 工具函数
│   ├── __init__.py                  # 空文件，标识为包
│   ├── config.py                    # API统一配置：管理密钥、模型等环境信息
│   └── adapter.py                   # 万能翻译器：把用户的"大白话"翻译成程序能听懂的结构化输入
│
├── main.py                          # 主程序入口：串联所有节点，构建创作流水线
│
├── app_streamlit.py                 # 网页界面：Streamlit前端，提供用户与智能体交互的操作台
│
└── requirements.txt                 # 项目依赖清单
```

### 8.2 关键技术组件

| 组件 | 功能 |
|---|---|
| **工作流编排引擎** | 管理节点流转、用户介入、状态持久化 |
| **输入适配器** | 支持各节点的独立启动，自动解析用户输入 |
| **风格语料库** | 存储作家风格特征标签，支撑风格混合 |
| **叙事理论库** | 存储三幕式、英雄之旅等叙事模型 |
| **版本管理系统** | 存储风格润色历史，支持版本对比与组合 |
| **创作日志生成器** | 汇总全部决策记录，生成创作手记 |

### 8.3 技术选型建议

| 组件 | 推荐选项 | 说明 |
|---|---|---|
| 工作流编排 | Dify / 自建 | 可视化搭建，或基于状态机自建 |
| 知识库 | 向量数据库（Milvus/Pinecone） | 风格语料的语义检索 |
| 大模型 | GPT-4 / Claude / 智谱GLM | 需有较强的文学理解与生成能力 |
| 文件解析 | python-docx / markdown | 支持 .docx/.txt/.md 的上传解析 |

## 九、应用场景

| 场景 | 适用人群 | 典型需求 |
|---|---|---|
| 文学创作 | 写作初学者、故事爱好者 | 将灵感发展为完整小说 |
| 内容生产 | 自媒体人、短视频编剧 | 快速产出叙事性脚本 |
| 游戏叙事 | 游戏策划、文案 | 构建角色故事与世界观 |
| 写作教学 | 学生、写作课教师 | 展示创作流程，学习叙事方法 |
| 文稿优化 | 已有稿件的作者 | 润色文字、评价质量、续写未完稿 |

## 十、项目创新点

| 创新维度 | 说明 |
|---|---|
| **流程创新** | 将文学创作从"不可见的灵感"转化为"可见的七步流程"，使创作可学习、可复制 |
| **交互创新** | 用户可在每个节点深度介入，实现真正的人机协作，而非单纯的AI代写 |
| **风格创新** | 风格混合器让用户像调酒一样调配文学风格，提供前所未有的风格控制自由度 |
| **学习创新** | 不仅产出作品，同时产出创作日志，使用户在写作中学习写作 |
| **灵活创新** | 支持任意节点切入、独立工具使用、文件上传续写，适配不同用户的创作习惯 |

## 十一、结语

博尔赫斯说：

> "我写作，不是为了名声，也不是为了特定的读者，我写作是为了光阴流逝使我心安。"

文思工坊想做的，是让每一个心中藏着一个故事的人，都有机会在光阴流逝之前，把它写下来。

它不是替代写作者的AI工具，而是一个陪伴写作者成长的智能创作伙伴。它以七步工作流为基础，以风格混合为特色，以人机协作为核心哲学，致力于降低文学创作的门槛，同时不降低文学创作的品质。
